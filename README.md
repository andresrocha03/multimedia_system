# Multimedia System (C++ / Java Swing)

This project implements a simple multimedia management system designed to practice object-oriented programming concepts. The system allows the creation and manipulation of multimedia objects such as photos and videos, demonstrating key OOP principles including inheritance, polymorphism, and abstraction.

The core multimedia model is implemented in C++, while a graphical interface is provided using Java Swing. The interface communicates with the C++ backend to display and manage multimedia objects.

### Main concepts demonstrated

- Abstract classes and pure virtual functions
- Polymorphism and dynamic dispatch
- Object management through pointers (C++)
- Comparison between C++ memory management and Java references
- Rule of Three for safe object copying

### Running the project

Compile and run the C++ backend:

```
cd cpp
make run
```
